Luftsensor auslesen - SK

Als Luftsensor verwenden wir den fortgeschrittenen Canāree I5 Luftsensor von Piera Systems.
Er kombiniert präzise Partikelzählung mit zusätzlichen Umwelt- und Gasparametern in einem kompakten Gerät.
Der Canāree I5 kann Partikel bereits ab 0,1 µm messen – ein Bereich, den die meisten herkömmlichen Feinstaubsensoren nicht abdecken.

Der Sensor liefert jede Sekunde eine solche Key,Value Rohzeile über USB. Wir verwenden pyserial um die Daten mit Python einzulesen.

Sensorwerte und Bedeutung

Die vom Canāree I5 gelieferten Rohdaten bestehen aus Schlüssel-Wert-Paaren im Format `KEY,VALUE`. Nachfolgend eine Übersicht der Werte:

Schlüssel

Bedeutung

PC0.1 – PC10

Partikelanzahl ≥ x µm pro 0,1 L Luft

PM0.1 – PM10

Partikelmassekonzentration in µg/m³

TEMP

Temperatur in °C

HUMID

Luftfeuchtigkeit in %

ATM

Luftdruck in hPa

VOCAQI

Luftqualitätsindex basierend auf VOC (0–500)

bVOCeq

geschätzte VOC-Konzentration in ppm

GASest

allgemeine Gasbelastung (modellabhängig)

CO2eq

CO₂-Äquivalent in ppm

Der letzte Eintrag in der Datenzeile ist die Seriennummer des Sensors.
Die Werte werden als fortlaufender CSV-String über die serielle Schnittstelle übertragen.

Einlesen roher Zeile

Liest eine Datenzeile vom Sensor und liefert None, wenn keine Daten anliegen.

    def lese_daten(self):
        line = self.ser.readline().decode('utf-8', errors='ignore').strip()
        return line if line else None

Parsen in Dict

Die Zeile wird an Kommas aufgeteilt und in ein Python‑Dict umgewandelt, um über die Keys direkten Zugriff auf die Messwerte zu ermöglichen. Eine ungerade Anzahl an Teilen signalisiert eine Geräte‑ID am Ende, die mit parts.pop() entnommen wird. Zusätzlich wird ein ISO‑Timestamp eingefügt.  

parse_sensor_line
def parse_sensor_line(self, line):
    parts = [p.strip() for p in line.split(',')]

    if len(parts) < 2:
        return None

    result = {}
    result['timestamp'] = datetime.now().isoformat()

    if len(parts) % 2 != 0:
        device_id = parts[-1]
        result['device_id'] = device_id
        parts = parts[:-1]

    i = 0
    while i < len(parts) - 1:
        key = parts[i]
        value = parts[i + 1]

        try:
            value = float(value)
            if value.is_integer():
                value = int(value)
        except ValueError:
            pass

        result[key] = value
        i += 2

    return result

Weitere bereitgestellte Methoden

  • get_rating_measurements(raw_line): Extrahiert die 5 Key-Measurements PM2.5, CO2eq, VOCAQI, TEMP, HUMID, die für die Bewertung der Luftqualität und Steuerung der Geräte notwendig sind.
  • speichere_json(daten, file): Hängt jedes Dict als eigene JSON‑Zeile an file an für Logging.
  • lese_daten_parsed: Liest Daten vom Sensor und gibt sie direkt als Python-Dict zurück.

Kurzbeispiel der Verwendung

Instanziiert das SensorReader‑Objekt, öffnet die serielle Schnittstelle und liefert alle Messwerte als strukturiertes Python‑Dict (inkl. Timestamp) und schließt die Verbindung. 

from sensorik.read_sensor_data import SensorReader

reader = SensorReader()
raw = reader.lese_daten()
if raw:
    data = reader.parse_sensor_line(raw)
    print(data)
reader.close()
