Raspberry Pi Einrichtung & Remote-Workflow - PP

1.SSH-Zugang am Pi aktivieren

Zuerst wurde SSH auf dem Pi aktiviert, um eine sichere Fernsteuerung über das Netzwerk zu ermöglichen:

  1. Raspi-Config öffnen:
    Am Pi einloggen (Monitor + Tastatur) und im Terminal ausführen:

    sudo raspi-config

  2. SSH aktivieren:
    Im Menü zu „Interfacing Options“ > „SSH“ navigieren und auf „Enable“ stellen.

  3. SSH-Dienst läuft:
    Ab jetzt akzeptiert der Pi SSH-Verbindungen automatisch nach jedem Systemstart.

2. IP-Adresse des Pi ermitteln

Um den Pi über das Netzwerk anzusprechen, wurde die aktuelle lokale IP-Adresse wie folgt ausgelesen:

hostname -I

Beispiel-Ausgabe:

192.168.178.68

Die Adresse wurde für alle späteren SSH- und VS Code-Remote-Verbindungen benötigt.

3. VPN-Verbindung ins THWS-Netz für Bitbucket etc.

Um aus dem externen Netzwerk auf interne Dienste (wie das THWS-Bitbucket-Repo) zugreifen zu können, wurde der VPN-Client openfortivpn eingerichtet:

  1. Installation: 

    sudo apt update sudo apt install -y openfortivpn
  2. Konfigurationsdatei anlegen:
    sudo nano /etc/openfortivpn/config



    Mit folgendem (angepassten) Inhalt:
    host = <vpn.thws.de>
port = 443
username = <thws_benutzername>
password = <thws_passwort>

  3. VPN-Verbindung herstellen:

    sudo openfortivpn

    → Die Verbindung bleibt solange aktiv, wie das Terminal offen bleibt.
    Beispielausgabe:

    FortiGate VPN SSL — Version x.x.x
Virtual IP: 10.x.x.x


4. Remote-Entwicklung mit VS Code

Für effiziente Entwicklung und Deployment wurde Visual Studio Code mit dem Plugin „Remote – SSH“ genutzt:

  • Remote-SSH-Extension installieren

  • Unten links das SSH-Symbol klicken → „Connect to Host…“

  • SSH-Adresse eingeben (z. B. airquality@192.168.178.68)

  • Nach Passwortabfrage verbindet sich VS Code direkt auf das Dateisystem und Terminal des Pi

  • So kann direkt auf dem Pi programmiert, getestet und deployed werden

Zusammenfassung

  • SSH und VPN erlauben vollwertiges Remote-Development am Pi

  • VS Code bietet direkten Zugriff auf Dateien, Terminal und Tools (Python, pip, git, etc.)

  • Alle Entwicklungs- und Deploymentschritte werden so komfortabel aus der Ferne durchgeführt
