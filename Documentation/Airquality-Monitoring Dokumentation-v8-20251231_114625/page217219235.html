FadeHelper

Stellt eine interpolate()-Funktion bereit, die zwei RGB-Werte über eine gegebene Schrittzahl linear überblendet.

inline RGB interpolate(const RGB& start, const RGB& target, uint16_t step, uint16_t maxSteps) {
  if (maxSteps == 0) return start;
  float frac = float(step) / maxSteps;
  return {
    uint8_t(start.r + (target.r - start.r) * frac),
    uint8_t(start.g + (target.g - start.g) * frac),
    uint8_t(start.b + (target.b - start.b) * frac)
  };
}
Erklärung:
Die Funktion berechnet einen Zwischenfarbwert auf einer geraden Linie zwischen start und target nach dem Verhältnis step/maxSteps. So entsteht ein sanfter Farbverlauf.

setColor(...)

void LedController::setColor(uint8_t r, uint8_t g, uint8_t b) {
  _prevR = r; _prevG = g; _prevB = b;
  _curR = r; _curG = g; _curB = b;
  for (uint16_t i = 0; i < strip.numPixels(); i++)
    strip.setPixelColor(i, strip.Color(r, g, b));
  strip.show();
}
Erklärung:
Schaltet alle LEDs sofort auf die übergebenen RGB-Werte. Speichert die aktuelle und die zuletzt dauerhaft gesetzte Farbe in den Member-Variablen _curR/G/B und _prevR/G/B.

setColorSmooth(...)
→ Initialisiert ein Fading-Intervall:

void LedController::setColorSmooth(uint8_t r, uint8_t g, uint8_t b, uint16_t steps, uint16_t interval) {
  stopBlinking();
  _prevR = r; _prevG = g; _prevB = b;
  _startR = _curR; _startG = _curG; _startB = _curB;
  _targetR = r;    _targetG = g;    _targetB = b;
  _fadeSteps = steps;
  _fadeInterval = interval;
  _currentStep = 0;
  _lastFadeTime = millis();
  _fading = true;
}
Erklärung:
Leitet ein sanftes Überblenden von der aktuellen Farbe (_curR/G/B) zur Ziel­farbe (r/g/b) ein. steps und interval definieren die Dauer und Geschwindigkeit des Fadings.

blink(...)
→ Toggle-Logik für Warnungen:

void LedController::blink(uint8_t r, uint8_t g, uint8_t b, uint32_t intervalMs) {
  stopBlinking();
  _blinkColor = { r, g, b };
  _blinkInterval = intervalMs;
  _lastBlinkTime = millis();
  _blinkState = false;
  _blinking = true;
}
Erklärung:
Aktiviert den Blinkmodus: Die LEDs wechseln in der angegebenen Farbe r/g/b im Intervall intervalMs zwischen an und aus.

handleFade()
→ Muss im Hauptloop aufgerufen werden und Entscheidet zwischen Blinken und Fading:

void LedController::handleFade() {
  uint32_t now = millis();

  // 1) Wenn Blinken aktiv: Blinken primär abarbeiten
  if (_blinking) {
    if (now - _lastBlinkTime >= _blinkInterval) {
      _lastBlinkTime = now;
      _blinkState = !_blinkState;
      for (uint16_t i = 0; i < strip.numPixels(); i++) {
        if (_blinkState)
          strip.setPixelColor(i, strip.Color(_blinkColor.r, _blinkColor.g, _blinkColor.b));
        else
          strip.setPixelColor(i, strip.Color(0, 0, 0));
      }
      strip.show();
    }
    return;
  }

  // 2) Sonst: Fading Schritt ausführen, wenn fällig
  if (!_fading) return;
  if (now - _lastFadeTime < _fadeInterval) return;
  _lastFadeTime = now;
  if (++_currentStep > _fadeSteps) {
    setColor(_targetR, _targetG, _targetB);
    _fading = false;
    return;
  }

  RGB start  = { _startR, _startG, _startB };
  RGB target = { _targetR, _targetG, _targetB };
  RGB cur    = interpolate(start, target, _currentStep, _fadeSteps);

  setColor(cur.r, cur.g, cur.b);
}
Erklärung:
Wird in jeder Loop-Iteration aufgerufen und entscheidet:
  1. Ob gerade geblinkt werden soll (bei erhöhter Gefahr)
  2. Ob ein Fading-Schritt fällig ist → führt diesen per interpolate() aus.


MqttManager

Vereinfacht die Verbindung zum MQTT-Broker und leitet eingehende Nachrichten an eine Callback-Funktion weiter.

MqttManager::generateClientId()

void MqttManager::generateClientId() {
  uint64_t chipid = ESP.getEfuseMac();
  char buf[32];
  snprintf(buf, sizeof(buf), "ESP32_%04X%08X", (uint16_t)(chipid>>32), (uint32_t)chipid);
  _clientId = String(buf);
}

Erklärung:
Erzeugt eine eindeutige Client-ID für die MQTT-Verbindung.
Dazu wird die weltweit einzigartige MAC-Adresse des ESP32-Chips verwendet und als Zeichenkette im Format "ESP32_<ChipID>" formatiert.
So wird sichergestellt, dass auch wenn mehrere Geräte gleichzeitig betrieben werden, diese sich nicht gegenseitig aus dem MQTT-Netzwerk verdrängen.


MqttManager::begin(...)

void MqttManager::begin(const char* server, uint16_t port) {
  generateClientId();
  _client.setServer(server, port);
}
Erklärung:
Initialisiert die MQTT-Verbindung mit der angegebenen Server-Adresse und Portnummer.
Vor dem Setzen der Verbindungsdaten wird einmalig die eindeutige Client-ID generiert.
Damit ist das Gerät korrekt im MQTT-Broker registriert und bereit für alle folgenden Verbindung- und Anmeldevorgänge.

MqttManager::setCommandCallback(...)

void MqttManager::setCommandCallback(std::function<void(const char*, const uint8_t*, unsigned int)> cb) {
  _client.setCallback([cb](char* topic, byte* payload, unsigned int length){
    cb(topic, payload, length);
  });
}
Erklärung:
Registriert die vom Anwender übergebene Callback-Funktion (cb), die ausgeführt wird, wenn eine neue MQTT-Nachricht eintrifft. Da PubSubClient eine anders geformte Signatur für seinen Callback erwartet, wird hier ein Lambda benutzt, das die Parameter einfach an cb weiterleitet.


MqttManager::reconnect()
→ Exponentielles Back-off bis zur erfolgreichen Verbindung:

void MqttManager::reconnect() {
  if (_client.connected()) return;
  unsigned long now = millis();
  if (now - _lastReconnectAttempt < _reconnectDelay) return;
  _lastReconnectAttempt = now;
  Serial.printf("MQTT connect (%s), delay %lums\n", _clientId.c_str(), _reconnectDelay);
  if (_client.connect(_clientId.c_str())) {
    _client.subscribe(MQTT_TOPIC);
    Serial.println("MQTT verbunden");
    _reconnectDelay = 2000;
  } else {
    Serial.println("MQTT Verbindungsfehler.");
    _reconnectDelay = min(_reconnectDelay * 2, (unsigned long)60000);
  }
}
Erklärung:
Sorgt dafür, dass das Gerät dauerhaft mit dem MQTT-Broker verbunden bleibt.
Es wird in jedem Loop-Durchlauf geprüft, ob eine Verbindung besteht.
  • Erfolgreicher Connect: Sobald die Verbindung steht, wird das gewünschte Topic abonniert und das Initial-Delay zurückgesetzt.
  • Fehlversuch + Back-off: Bei Verbindungsproblemen wird der nächste Verbindungsversuch um einen exponentiellen Zeitraum verzögert (maximal 60 Sekunden), sodass das System weiterhin auf andere Aufgaben reagieren kann und nicht blockiert.

WiFiManager.cpp

Kapselt Aufbau und Überwachung der WLAN-Verbindung

unsigned long WiFiManager::_lastAttempt = 0;

void WiFiManager::begin(const char* ssid, const char* password) {
  WiFi.begin(ssid, password);
  Serial.print("WLAN verbindet");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print('.');
  }
  Serial.println("\nWLAN verbunden!");
}

void WiFiManager::maintain() {
  if (WiFi.status() != WL_CONNECTED) {
    unsigned long now = millis();
    if (now - _lastAttempt > 5000) { // Alle 5s versuchen
      Serial.println("WLAN getrennt, reconnect...");
      WiFi.reconnect();
      _lastAttempt = now;
    }
  }
}

Erklärung

Die Klasse übernimmt das Initialisieren der WLAN-Verbindung anhand der in config.h hinterlegen SSID und Passwort.
Im Setup baut begin() die Verbindung auf und blockiert bis zum erfolgreichen Verbindungsaufbau.
Die Methode maintain() überprüft in jeder Loop-Iteration, ob die Verbindung noch steht und stößt im Fehlerfall alle 5 Sekunden einen Reconnect an, um unnötige Wiederholungen zu vermeiden und das System zu entlasten.

main.cpp

Orchestriert Setup, Loop und die Übersetzung eingehender MQTT-Nachrichten in LED-Aktionen.

AirQualityLevel-Enum & Parser

enum class AirQualityLevel {
  SehrGut,
  Gut,
  Maessig,
  Schlecht,
  SehrSchlecht,
  Unbekannt
};

AirQualityLevel parseAirQuality(const String& msg) {
  String m = msg;
  m.toLowerCase();
  m.trim();
  if (m == "sehr gut") return AirQualityLevel::SehrGut;
  if (m == "gut")      return AirQualityLevel::Gut;
  if (m == "maessig")  return AirQualityLevel::Maessig;
  if (m == "schlecht") return AirQualityLevel::Schlecht;
  if (m == "sehr schlecht") return AirQualityLevel::SehrSchlecht;
  return AirQualityLevel::Unbekannt;
}

Erklärung:

  • Das Enum definiert alle möglichen Luftgüte-Stufen, die das System kennt.
  • Die Parser-Funktion wandelt eine empfangene Textnachricht in einen dieser Enum-Werte um.
  • Durch toLowerCase() und trim() wird das Message-Format robust gegen Groß-/Kleinschreibung und überflüssige Leerzeichen gemacht.
  • Treffer in den if-Blöcken ordnen das Ergebnis der passenden Stufe zu → unbekannte oder fehlerhafte Nachrichten landen in Unbekannt.


MQTT-Callback

void onMqttMessage(const char* topic, const uint8_t* payload, unsigned int length) {
  StaticJsonDocument<256> doc;
  DeserializationError err = deserializeJson(doc, payload, length);
  if (!err && doc.containsKey("r") && doc.containsKey("g") && doc.containsKey("b")) {
    int r = doc["r"];
    int g = doc["g"];
    int b = doc["b"];
    uint16_t steps   = doc["steps"]   | FADE_STEPS_DEFAULT;
    uint16_t delayMs = doc["delayMs"] | FADE_INTERVAL_DEFAULT;
    leds.setColorSmooth(safeColor(r), safeColor(g), safeColor(b), steps, delayMs);
    return;
  }

  // Ansonsten: reiner Text-Messagehandler
  String msg;
  for (unsigned int i = 0; i < length; i++) msg += (char)payload[i];
  msg.trim();

  AirQualityLevel level = parseAirQuality(msg);
  switch (level) {
    case AirQualityLevel::SehrGut:
      leds.stopBlinking();
      leds.setColorSmooth(0, 255, 0);
      break;
    case AirQualityLevel::Gut:
      leds.stopBlinking();
      leds.setColorSmooth(127, 255, 0);
      break;
    case AirQualityLevel::Maessig:
      leds.stopBlinking();
      leds.setColorSmooth(255, 165, 0);
      break;
    case AirQualityLevel::Schlecht:
      leds.stopBlinking();
      leds.setColorSmooth(200, 0, 0);
      break;
    case AirQualityLevel::SehrSchlecht:
      leds.blink(255, 0, 0, 250);
      break;
    default:
      leds.stopBlinking();
      leds.setColorSmooth(128, 128, 128);
      break;
  }
}
Erklärung:
Reagiert auf eingehende MQTT-Nachrichten. Entweder wird ein JSON-Kommando (r/g/b, steps, delayMs) ausgeführt oder eine einfache Textnachricht in eine Luftgüte-Stufe übersetzt, um die Ampelfarbe bzw. Blinkmodus zu setzen.

Setup

void setup() {
  Serial.begin(115200);
  leds.begin();
  WiFiManager::begin(WIFI_SSID, WIFI_PASSWORD);
  mqttMgr.begin(MQTT_SERVER, MQTT_PORT);
  mqttMgr.setCommandCallback(onMqttMessage);
}

Erklärung:

  1. Serial.begin(115200) → Initialisiert die serielle Schnittstelle zur Ausgabe von Debug- und Statusmeldungen im Monitor.
  2. leds.begin() → Startet den NeoPixel-Ring und löscht alle LEDs (sichert einen definierten Ausgangszustand).
  3. WiFiManager::begin(...) → Baut die WLAN-Verbindung mithilfe der definierten SSID und des Passworts auf und blockiert bis zum Erfolg.
  4. mqttMgr.begin(...) → Konfiguriert die Adresse und den Port des MQTT-Brokers.
  5. mqttMgr.setCommandCallback(onMqttMessage) → Registriert die Funktion, die eingehende MQTT-Nachrichten verarbeitet und in LED-Befehle übersetzt
void loop() {
  leds.handleFade();
  WiFiManager::maintain();
  mqttMgr.loop();
}

Erklärung:

  1. leds.handleFade() → Führt in jeder Iteration entweder einen Blink- oder Fade-Schritt aus, je nachdem, welcher Modus aktiv ist.
  2. WiFiManager::maintain() → Überprüft den WLAN-Status und verbindet bei einem Abbruch automatisch neu.
  3. mqttMgr.loop() → Hält die MQTT-Verbindung am Leben, verarbeitet eingehende Nachrichten und löst bei Bedarf den Reconnect aus.

Enthält alle zentralen Build- und Umgebungsoptionen für das PlatformIO-Projekt.

Erklärung:

  • platform: Gibt die Plattform (espressif32 für ESP32) an.

  • board: Wählt das konkrete Board-Modell (hier rymcu-esp32-devkitc).

  • framework: Nutzt das Arduino-Framework für einfaches ESP32-Programming.

  • monitor_speed: Stellt die Geschwindigkeit des seriellen Monitors ein (115200 Baud).

  • lib_deps: Listet alle verwendeten Bibliotheken samt Versionsnummern, die bei jedem Build automatisch installiert werden:
    • ArduinoJson für das Parsen von JSON-Nachrichten.

    • Adafruit NeoPixel zur Ansteuerung des LED-Rings.

    • PubSubClient für MQTT-Kommunikation.

Damit ist sichergestellt, dass das Projekt auf jedem Rechner und in jeder Entwicklungsumgebung reproduzierbar gebaut werden kann.
